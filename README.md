# Кварта

Лендинг обжарки кофе «Кварта» (Минск) с формой заявки на Next.js, Postgres (Neon) и копией заявок в Telegram. Тестовое задание VitAi World.

## Как шла работа с ИИ

Работал в Claude Code. Экспорты сессий приложены к отправке, в них весь ход работы с моими правками и решениями.

### Подготовка

- Начал с заготовленной папки-шаблона (составил ее сам для работы на своем стеке еще давно), в которой лежит свод правил для Claude (`CLAUDE.md`): порядок подготовки к проекту, правила кода и комментариев, коммиты по шагам, обязательные проверки и тесты, чек-лист технического аудита, SEO и доступность. К нему прилагается мой профиль разработчика, чтобы ИИ учитывал, с какими технологиями я уже работал, а какие для меня новые.

### Прототип (макет)

Дизайн ИИ сделал прототипом-артефактом, а я выступал куратором: выбирал направление и давал правки, пока результат не перестал выглядеть сгенерированным.

За сессию прототипа было около 50 моих сообщений с правками. Итоговый прототип D2 (десктоп и телефон) стал макетом, по которому сверстан сайт.

### Работа с технической стороной

- Создал репозиторий Git, натроил Vercel, добавил переменные окружения, связал все с локальной папкой проекта, проинциализировал Next.js 16 и сделал коммит.
- Стартовый промпт написал сам: задача, стек (Next.js 16, App Router, TypeScript, Neon, Vercel), требования ТЗ к форме и бэкенду и конкретные приёмы для них, SEO и безопасность. ИИ должен был сначала составить пошаговый план, где каждый шаг это коммит, и задавать вопросы с вариантами ответа там, где что-то не уточнено.

## Допущения

- Использую Neon как хранилище для заявок, т.к. на Vercel файл/SQLite не сохраняются между запросами, плюс повторные заявки в течение 10 минут можно отсечь с помощью SQL-запроса с ON CONFLICT.

- npm audit показывает уязвимости только в dev-зависимостях линтера, на прод они не влияют

- Телефон мастерской `+375 29 000-00-00` это заглушка: клиент вымышленный, номера в ТЗ нет.

- Каталог и цены лежат в коде: админки в ТЗ нет. Сумму заказа сервер пересчитывает по этому каталогу, цифрам из браузера не доверяет.

- В подписку можно выбрать один или два сорта. Если выбран один, привозим две пачки его.

- Вместо встроенной карты нарисована схема и стоят ссылки на Яндекс Карты: встроенная карта тяжёлая и требует ослабить CSP.
